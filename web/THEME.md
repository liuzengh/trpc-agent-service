# 管理控制台视觉主题：方案 F

管理 Web 使用米白、森林绿、陶土橙与雾蓝。公开文档站仍独立构建，
此主题不改变登录、权限、保存、校验、发布或渠道启停的业务语义。

## 入口与职责

- `app/theme.css`：唯一基础色表，定义表面、文字、操作、分类和状态角色。
- `app/layout.tsx`：先加载主题，再加载 `app/globals.css`。
- `app/globals.css`：导航、表单、按钮、表格、反馈与响应式外壳。
- `app/login/login.module.css`：登录页双栏布局，窄屏缩成单列表单。
- 各业务 CSS Module 和画布内联样式使用 CSS 变量，不复制调色板。
- `data-resource-category`：Runtime Profile 与 Agent Requirements 共用的
  资源分类标识；对应变量也可用于登录页的产品介绍。

## 色彩分工

| 角色 | 颜色 / token | 用途 |
| --- | --- | --- |
| 主色 | `#245C4F` / `--primary` | 主要操作、选中与焦点 |
| 副色 | `#AD674B` / `--secondary` | 陶土橙品牌点缀 |
| 副色文字 | `#8B4E37` / `--secondary-ink` | Tools 标签、发布说明标题 |
| 点缀 | `#537F98` / `--accent` | 雾蓝图形与信息边框 |
| 信息文字 | `#365E74` / `--info-ink` | Knowledge、草稿标识与说明 |
| 底色 | `#F6F3EC` / `--bg` | 工作区画布 |
| 内容表面 | `#FFFEFA` / `--surface` | 卡片、表单 |

正文不要直接使用浅色点缀值；使用对应的 `*-ink` / `*-soft` 配对。
保存和校验是中性次级按钮，不为每个动作增加一种高饱和颜色。

Models 使用森林绿，Tools 使用陶土橙，Knowledge 使用雾蓝，Storage
使用中性色。选中的具体资源仍以森林绿高亮；分类色不能表示连接成功。
成功、警告、错误使用独立 `--success`、`--warning`、`--danger` token，
保留原有图标、标签与状态说明。

## 验证

`npm test` 包含主题的 13 组文字对比度检查、变量引用检查、分类标识与
登录交互回归。浏览器视觉验收还需要检查桌面和窄屏的溢出、字段对齐、
弹窗、焦点及错误提示；单元测试不替代浏览器检查。

本轮视觉验收使用独立浏览器中的示例 API 响应；页面、组件和生产 CSS
均来自真实 Web 构建。示例校验状态不代表已连接模型或启动机器人。
