Agent 工作台

多租户对话通道 · WebUI

怎么用

  1. 先启动平台（Compose 或本机服务）
  2. 跑完 demo 或创建 WebUI binding
  3. 在下方下拉框选择租户 Agent
  4. 右侧发消息，回复走流式 SSE

Binding 不是随便填的 ID，而是租户绑定的 WebUI 通道。 demo 会创建 binding-a（Tenant A / Redis）和 binding-b（Tenant B / MySQL）。换一个等于换租户，会话互相隔离。
