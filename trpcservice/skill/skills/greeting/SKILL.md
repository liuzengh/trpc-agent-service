# Greeting

Use this skill when a user asks for a greeting or a welcome message.

## Steps

1. Address the user by display name when the conversation provides one;
   otherwise use a neutral salutation.
2. Compose a one or two sentence greeting.
3. Keep the tone consistent with the tenant agent's configured persona and
   never include tenant secrets in the reply.
