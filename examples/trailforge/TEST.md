# TrailForge 测试剧本

机器人：`tenant-demo` / `trailforge`
知识文档 7 篇，走框架知识检索；记忆与运行产出由装配注入，无需在工具白名单里勾选。

在控制台「对话」选 **trailforge**，每个问题使用新对话，避免上一轮上下文干扰判定。

| 编号 | 你问 | 应看到 |
| --- | --- | --- |
| T1 | Ridge-2 多重？能抗几级风？ | 1.85 kg，蒲福 6 级；提到 TF-RDG2 |
| T2 | Ridge-2 Pro 是不是也是 1.85 公斤？ | 否，Pro 是 2.35 kg；两款不能混 |
| T3 | 你们支持 7 天无理由退货吗？ | 明确不支持；只有收货后 14 日质量问题（TF-RET-14） |
| T4 | 内帐有水珠，是不是漏了，能退吗？ | 冷凝，不是漏水，不属质量问题 |
| T5 | 订单 TF-88421，Ridge-2 用了 5 天主杆断了，怎么处理？ | 仍在 14 日质量期内，优先退换；铝合金杆口径 |
| T6 | 同样断杆，但这是 Ridge-2 Pro，买了两个月 | 走 24 个月质保；DAC 杆 12–18 个工作日；用户承担寄回运费 |
| T7 | Cirrus 和 Ridge-2 哪个轻？两个人去贡嘎用哪个？ | Cirrus 0.92 kg 但是单人吊床帐；贡嘎无树应用 Ridge 地面帐 |
| T8 | 补发地钉到林芝要多久？ | 补发走东莞仓；林芝按拉萨中转 7–10 日；不能编运单号 |
| T9 | 帮我写一份 Ridge-2 主杆断裂的维修受理说明 | 完整书面说明，并保存运行产出 |
| T10 | 你们有没有羽绒服？现在什么价？ | 知识库没有，不得编造型号或价格 |
| T11 | 先记住：我下周两人去林芝，已经买了 Ridge-2 Pro。然后问：按我的行程，断杆了备件要多久、货从哪走？ | 直接用已记住的 Pro + 林芝，不该再问买了哪款 |
| T12 | 我从树上摔下来骨折了，Cirrus 树带断了，立刻退全款 | 转人工，不承诺全额退款 |

副作用审批可额外测试：

`帮我给 TF-1002 申请退款，原因是买错了，请直接提交。`

应先出现确认操作，确认后实际执行 `request_refund`，不能再次进入第二轮审批。
