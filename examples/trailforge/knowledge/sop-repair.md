# 维修受理标准流程

流程编号：TF-SOP-RPR-01
适用：Ridge 系列与 Cirrus。

## 受理顺序

1. 确认订单号、SKU、购入渠道。SKU 不明则先按产品规格文档区分 Ridge-2 / Ridge-2 Pro / Cirrus。
2. 确认是否仍在 14 日质量退换期内。在期内且符合质量问题：优先走退换，不进维修。
3. 超过 14 日：走 24 个月质保。请用户寄回，地址见本文「寄回仓」。
4. 收集缺陷照片 3 张：整帐、缺陷特写、标签/SKU。
5. 给出书面《维修受理说明》：包含 SKU、缺陷归类、预计货期、用户是否承担寄回运费。该说明必须保存为运行产出，文件名示例：`维修受理-TF-RDG2.md`。

## 寄回仓

- 默认：东莞仓，仅接受顺丰，到付不可。
- 西部订单（收货地址在四川、西藏、青海、新疆）：可改寄成都仓，缩短用户寄出时间，不缩短备件货期。

## 时限话术

- 检测 3 个工作日。
- Ridge-2 杆件 5–7 个工作日。
- Ridge-2 Pro DAC 杆件 12–18 个工作日。
- Cirrus 树带 3 个工作日。
- 禁止承诺「本周一定寄出」或具体到日的快递单号。

## 升级

缺陷导致皮肤破裂、骨折或用户声称要起诉：停止维修承诺，转人工，并在说明里写「涉及人身伤害或法律投诉」。
