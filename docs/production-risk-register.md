# 生产风险清单与缓解措施

本清单是根目录 README “至少八项生产风险与缓解措施”交付物的可验收版本。风险状态不替代测试证据；每次生产变更都应复核对应的预防、检测和恢复动作。

| # | 风险 | 预防与检测 | 恢复措施 |
| --- | --- | --- | --- |
| 1 | IM 平台重试、客户端重发造成重复回复 | 以 tenant/channel/message_id 去重；执行 claim、trace fencing 与 Web request_id 幂等；审计执行状态 | 重放时返回既有结果；人工核对消息 receipt 与 Outbox 状态 |
| 2 | Worker 崩溃或 Kafka rebalance 导致处理丢失/重复 | 业务成功或 DLQ 落库后才提交 offset；非法记录进入 DLQ；同一 session 使用稳定分区键 | 从未提交 offset 重放；按 DLQ 事件修复并再投递 |
| 3 | Outbox 已发送、数据库更新失败造成外部重复投递 | 投递租约、持久 receipt、渠道幂等键；不支持外部幂等的渠道显式记录“至少一次”语义 | 对照 receipt、渠道后台与审计记录去重；必要时人工撤回/补偿 |
| 4 | 跨租户读取或写入 | 所有控制面/平台数据表带 tenant key 与 RLS；应用层解析成员角色；RLS 集成测试覆盖读写 | 立即暂停受影响 binding，轮换凭据，按 trace/audit 界定影响范围 |
| 5 | PostgreSQL、Redis、Kafka、S3 短暂故障 | 超时、错误分类、重试与健康探针；Store/Sender/Runtime 指标与告警 | Kafka 重放、Outbox 重试；恢复依赖后验证 readyz 与积压 |
| 6 | 模型超时、限流或成本失控 | context 取消、模型 usage ledger、租户预算、Redis 令牌桶与成本告警 | 降级为可解释错误或人工通道；暂停对应应用/Provider 并复核预算 |
| 7 | 工具越权、危险参数或不受控出网 | tools.allowed 白名单、角色授权、参数校验、风险级别与审计；未知工具装配失败 | 停用配置版本或工具，撤销凭据，依据最小化审计追踪影响 |
| 8 | 密钥、正文或个人数据进入日志/追踪 | 只允许受管 env: Secret 引用；端点 allowlist；正文与摘要使用 keyed HMAC；OTel 属性白名单 | 轮换泄露密钥，隔离日志访问，按审计元数据执行数据处置 |
| 9 | Session/Memory/Knowledge 在多节点出现陈旧读或迁移不一致 | PostgreSQL 事实源、配置版本不可变、Redis 失效通知；迁移采用向前复制、校验、切换 | 回退到上个配置版本；保留原后端只读并对账后再切换 |
| 10 | 发布、迁移或容量变化导致服务不可用 | Migration Job 先于 Deployment；滚动更新、PDB、探针、资源限制与 HPA；压测前设定容量基线 | 停止 rollout，保留向前迁移状态；按发布 runbook 扩容或回滚应用镜像 |
| 11 | 备份不可恢复或密钥轮换破坏服务 | 定期执行受控备份/恢复和密钥轮换 smoke；脚本只调用绝对路径的审核包装器 | 使用最近验证的恢复点，恢复后执行 Kubernetes smoke 和功能抽检 |

## 验收要求

- 每项生产变更至少引用一项表中的预防/检测措施。
- 备份恢复、Secret 轮换、真实 IM 和压测属于外部环境演练；其执行日志必须作为发布证据保存，不能以仓库脚本存在替代。
