## 交付范围

- 新增 `trpcservice/telemetry`：server-owned Config（mode=none 默认/otlp；endpoint、environment allowlist、bounded version、sampling ratio [0,1]、batch/queue/timeout 全有界；insecure 仅 loopback）；`Compose`（ModeNone 不建 exporter/goroutine；OTLP 建 trace+metric gRPC exporter 与 SDK provider，部分失败反向清理）；`Runtime.Shutdown` 幂等有界、`ForceFlush` 有界、失败 category-only 限频日志；`Runtime` 同时实现 gateway `Telemetry`（producer span/InjectCarrier/metric）与 worker `WorkerTelemetry`（attempt span + links、job started/finished/inflight）接口。
- 结构化日志：注入式 `slog` JSON handler（production-owned 单行 JSON）；稳定字段 allowlist（event/component/operation/outcome/error_category/context_state/attempt/candidates/hydrated/scanned/enqueued/route/method/status_class 等）；值截断与控制字符清除（单行可解析）；`SafeError` 只放行 category 形态 sentinel（含数字/多冒号/raw 文本一律坍缩为 unknown）；`Fingerprint` 有界盐化指纹；rate-limited 事件避免洪泛。
- 低基数 metrics：`trpcagent.http.requests/.request.duration/.inflight`、`trpcagent.queue.operations`、`trpcagent.worker.jobs`、`trpcagent.completion.outcomes`、`trpcagent.outbox.dispatches`、`trpcagent.channel.outcomes`、`trpcagent.memory.mutations`、`trpcagent.vector.tasks`、`trpcagent.retrieval.outcomes`、`trpcagent.rebuild.batches`、`trpcagent.runtime.states`、`trpcagent.telemetry.attributes_dropped`。attributes 仅 allowlist（component/operation/outcome/error_category/channel[allowlist]/method/route template/status_class/backend_kind/worker_kind/filtered_reason/candidates/hydrated/scanned/enqueued/attempt）；webhook 路由模板 `/webhook/{channel}`；status 按 class 聚合；latency 固定 bucket（秒）。
- 跨异步边界 correlation：`queue.AgentJob` 增加可选 `Telemetry *TelemetryCarrier`（W3C traceparent only；旧 schema 解码不变，`Validate` 不受影响）；gateway producer span 注入 carrier；worker attempt span link producer span（missing/invalid carrier → 新 server span + context_state=missing|invalid，不失败）；retry/reclaim 新 attempt span 天然隔离。
- 接线（全部 additive/nil-safe，不改业务算法）：`web.Server.SetTelemetryMiddleware` + Handler() 内惰性 per-request 解析（组装时序安全）；`gateway.Gateway.WithTelemetry`；`worker.Config.Telemetry`（attempt ctx 为局部变量，不写共享 record.ctx，renew goroutine 无 data race）；production assembly `assembleTelemetry`（先 telemetry 后业务组件）+ Stop 顺序（入口/worker/dispatcher/vector → bounded ForceFlush → Shutdown）+ ForceFlush/Shutdown 使用独立 fresh contexts（不继承已取消 signal ctx）；`productionAssemblyDependencies.Telemetry` test seam。
