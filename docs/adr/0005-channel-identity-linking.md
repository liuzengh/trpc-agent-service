# ADR-0005：渠道身份关联使用短时单次证明（已废弃）

- 状态：**已废弃（2026-09-10）**
- 日期：2026-09-09

原方案曾设计通过机器人私聊 `/link` 将外部 IM 身份关联到平台用户。实践发现这会把“登录账号”“机器人路由”“外部消息参与者”三个概念耦合，增加用户理解成本和跨机器人一致性问题，因此废弃。

当前决策：平台账号只由本地账号、企业微信、飞书、OIDC 登录建立；不提供消息身份绑定、关联码、历史认领或独立“我的会话”功能。Channel/Binding 只负责机器人消息路由。可信企业身份源若能提供与登录身份完全一致的官方成员标识，可在服务端做确定性访问控制解析，但不形成用户可管理的机器人绑定关系。
