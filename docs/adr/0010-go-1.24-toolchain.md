# ADR-0010：统一采用 Go 1.24 工具链

- 状态：Accepted
- 日期：2026-09-11

## 背景

项目最初希望保持 Go 1.21，以贴近 tRPC-Agent-Go 根模块声明的最低版本。当前实现已经组合 Qdrant、OpenClaw、OIDC、OpenTelemetry、S3 与较新的 `golang.org/x/*` 模块。通过 `go list -m -f '{{if .GoVersion}}{{.Path}} {{.GoVersion}}{{end}}' all` 核验，当前依赖图中已有多个模块明确声明 Go 1.24 或 1.24.0/1.24.1；继续把项目声明降为 1.21 会造成 toolchain 自动切换、CI/本地不一致，或直接无法构建。

## 决策

项目、CI 和 Docker builder 统一使用 Go 1.24.x，`go.mod` 保持 `go 1.24.1`。本地开发最低使用 1.24.1，同一 1.24 补丁线可由 CI 验证。升级新的 Go 大版本前必须同时验证：

1. `go mod verify`、`go vet ./...`、全量测试和 Race；
2. PostgreSQL、Redis、Kafka、S3 真实适配器门禁；
3. 生产镜像构建与 Kind smoke；
4. tRPC-Agent-Go 及其拆分模块声明的 GoVersion。

## 影响

- 获得单一、可复现的本地/CI/容器编译基线。
- 不再承诺 Go 1.21 源码兼容性；这不是框架 API 版本变更。
- 若未来依赖图重新允许较低版本，也不自动降级，必须用新的 ADR 评估维护成本与安全更新。
