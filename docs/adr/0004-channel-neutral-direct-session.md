# ADR-0004：跨通道身份可统一，但会话默认独立

- 状态：**已接受**
- 日期：2026-09-10

同一租户、同一 Agent 从 Web、企业微信、Telegram、飞书发起的对话，各 Channel/Binding Conversation 默认保持独立 Session。平台账号由登录体系建立；外部 IM sender 不通过机器人或关联码绑定平台账号。群聊始终按群 conversation 独立建 Session。

这个选择把“登录身份”和“消息路由”明确拆开。不同 IM 平台具有不同的群聊、线程、撤回、重试和消息顺序语义，强行跨渠道续写同一 Session 会扩大并发与语义污染风险。

Console 当前不提供独立“我的会话”目录；Web 对话页只恢复自己的网页会话。若未来出现明确的跨渠道续聊需求，应重新设计，而不是通过身份猜测或机器人绑定隐式合并。
