## 二、风险清单

| # | 风险 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| 1 | **范围蔓延**：README「架构为主」vs 任务「完整实现」不一致 | 交付失控 | 阶段 0 先对齐交付形态，按阶段收束 |
| 2 | **后端选型分歧**：任务强制 MySQL+Redis，参考 PR 用 PG+Qdrant+MinIO | 返工 | 明确强制项与讨论项，非强制后端先征得同意 |
| 3 | **tRPC-Agent-Go API 漂移**：框架迭代快，API 可能变更 | 编译失败 | 锁定版本，懒加载按模块查阅官方文档 |
| 4 | **多租户数据越权**：模型经工具间接访问他租户数据 | 安全事故 | 授权由后端可信上下文判定，工具白名单 + Guardrail + 强制租户过滤 |
| 5 | **跨节点会话一致性**：并发写同一 session 乱序 | 数据错乱 | Redis 分布式锁 + 事件序列号 + MySQL 事务 |
| 6 | **IM 消息重复/乱序** | 重复回复 | 消息 ID 幂等表 + 去重 + 串行化 |
| 7 | **密钥泄漏**：模型 key/IM token/DB 密码进日志或 trace | 安全 | Secret 注入 + 脱敏 + 日志审计 |
| 8 | **节点故障**：Worker 崩溃导致消息丢失 | 丢消息 | Redis Streams XAUTOCLAIM 认领 + DLQ + 重试 |
| 9 | **模型超时/工具失败** | 卡死/资源泄漏 | context 取消 + goroutine 生命周期 + Runner 事件通道排空 |
| 10 | **成本失控**：token/沙箱/存储无配额 | 超预算 | 租户级配额 + 用量统计 + 限流 |
| 11 | **沙箱逃逸**（若引入沙箱） | 安全 | 非 root、禁特权、只读根 FS、NetworkPolicy |
| 12 | **测试环境依赖**：集成测试需 MySQL/Redis | 不稳定 | testcontainers 或 mock，保证可重复执行 |
