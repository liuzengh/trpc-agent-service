## 多节点多租户可用性测试

以下四份文档定义测试准备、操作步骤和验收标准，不包含已执行测试的结果。按被测 PR 的实际部署适配使用，执行证据保存在独立运行目录。

- [恢复后能继续对话](多节点多租户可用性测试/01-恢复后能继续对话.md)：先建立单节点和双节点业务基线，再故障节点，验证接管后的原会话新消息。
- [在途任务接管](多节点多租户可用性测试/02-在途任务接管.md)：覆盖接收、执行、结果提交与回复投递阶段，检查原任务恢复、租户隔离和重复处理。
- [单主机多容器实例部署的可用性](多节点多租户可用性测试/03-单主机多容器实例部署的可用性.md)：检查多实例共存、实例故障、重新加入和反向故障，区分接管与容器重启。
- [跨主机高可用](多节点多租户可用性测试/04-跨主机高可用.md)：覆盖整机故障、网络隔离、共享依赖和故障域，明确业务恢复及数据一致性要求。
