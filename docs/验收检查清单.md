  - 访问: `http://127.0.0.1:8080/healthz`
  - 验证: HTTP 200 OK

- [ ] **4. 管理前端加载成功**
  - 访问: `http://127.0.0.1:5173`
  - 验证: Vue3 SPA 正常渲染

## 登录与权限管理

- [ ] **5. 用户注册成功**
  - 执行: `POST /auth/register`
  ```json
  {
    "tenant_id": "t-test",
    "user_id": "admin",
    "password": "secure123",
    "role": "owner"
  }
  ```
  - 验证: HTTP 201, 返回 Member 对象

- [ ] **6. 用户登录获取 JWT**
  - 执行: `POST /auth/login`
  ```json
  {
    "tenant_id": "t-test",
    "user_id": "admin",
    "password": "secure123"
  }
  ```
  - 验证: HTTP 200, 返回 `{token: "eyJhbG...", member: {...}}`

- [ ] **7. 无认证访问被拒绝**
  - 执行: `GET /tenants`
  - 验证: HTTP 401 Unauthorized

- [ ] **8. 携带 token 访问成功**
  - 执行: `GET /tenants` with `Authorization: Bearer <token>`
  - 验证: HTTP 200, 返回租户列表

- [ ] **9. Member 角色权限受限**
  - 注册 member 角色用户
  - 尝试 `POST /agents` 创建 agent
  - 验证: HTTP 403 Forbidden

## 业务功能

- [ ] **10. 租户 CRUD 可用**
  - `POST /tenants` 创建租户
  - `GET /tenants` 获取租户列表
  - `PUT /tenants/{id}` 更新租户
  - `DELETE /tenants/{id}` 删除租户（软删除）

- [ ] **11. Agent 发布/回滚可用**
  - `POST /agents` 创建 agent
  - `POST /agents/{id}/publish` 发布 agent（创建不可变版本）
  - `GET /agents/{id}/versions` 查看版本列表
  - `POST /agents/{id}/rollback?version=1` 回滚到指定版本

- [ ] **12. Tool/RBAC 可用**
  - `POST /tools` 创建工具（function 或 mcp 类型）
  - `PUT /tools/{id}/grants/{agentID}` 授予 agent 工具权限
  - `GET /tools/{id}/grants` 查看授权列表
