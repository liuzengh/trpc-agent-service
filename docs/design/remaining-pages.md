# 控制台页面设计参考

本页汇总控制台主要页面的布局与交互约束。功能契约以 [前端设计](frontend-ui.md) 和 [项目规格](../complete-development-plan.md) 为准，自动化证据见 [验收文档](../acceptance.md)。

控制台统一采用冷灰白、Apple Blue、细分隔线和固定侧栏；`webui/src/tokens.css` 是颜色、间距和组件状态的事实源。下列图片用于说明信息层级与操作位置，示例名称、消息和状态不作为测试数据。

| 页面 | 设计图片 | 布局与操作重点 |
| --- | --- | --- |
| 对话 | [chat.png](chat.png) | 应用列表、主对话区、会话信息；只保留网页对话，输入框固定在主区底部 |
| 执行记录 | [executions.png](executions.png) | 左侧记录列表、右侧运行详情；后台轮询仅在内容变化时更新界面 |
| 会话 | [sessions.png](sessions.png) | 会话索引、来源渠道、真实正文、归档和会话产出；不提供外部账号与平台用户的手工身份关联；投递事实统一留在执行记录 |

## 页面语义边界

- 对话里的应用可用状态不是模型健康探测结果。流中断、重试和切换应用必须保护会话边界；新会话需遵守后端活动会话契约。
- 执行步骤只能根据明确事件展示；没有证据的阶段保持未知，不能由尝试次数推断 DLQ。审计只显示脱敏内容，不能充当对话原文。
- 会话详情从会话索引读取摘要，从消息接口读取完整聊天历史。会话归档释放活动会话，归档属于正常生命周期状态，不使用红色状态。
- 投递状态根据出站记录解释；缺少失败／重试详情时不添加重新发送和终止操作。
- 知识与用户偏好按当前租户和机器人作用域读取；运行产出只在对应会话中按 Session 定位和查看。
- 系统状态只表达依赖探测和已暴露配置，不添加没有数据来源的吞吐、成本、CPU 或在线率图表。

对应的 `*-prompt.txt` 文件记录图片的生成参数，便于在视觉规范调整时重建参考图。
