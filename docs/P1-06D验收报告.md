## 交付范围

新增 `trpcservice/vector/retrieval`（全部为新文件，未修改受保护边界）：

- `contract.go`：server-owned `Config`（model/version/schema/dimension、source allowlist、MaxTopK≤`vector.MaxTopK`、candidate multiplier/total/rounds、query byte limit、hydration batch/chunks、operation timeout），`WithDefaults` 对缺失或超界配置 fail closed；无 fake/memory 回退。
- `errors.go`：类别-only 安全错误（`ErrInvalidConfig/ErrInvalidRequest/ErrUnavailable/ErrPartial`），不携带 raw backend text。
- `service.go`：`Retrieve` 管道——可信 `TenantContext` 校验→请求边界校验（query 非空/≤MaxQueryBytes/UTF-8；TopK 1..MaxTopK；MinScore finite [0,1]；source type 必须在 server allowlist 内；caller 无 tenant/collection/namespace/partition/raw filter/expression 字段）→注入式 Embedder（bounded context；dimension/model/version 必须与 server config 一致）→`VectorStore.Search`（tenant context 由 server 注入；PG 事务外；每轮 bounded context）→candidate validation（document ID `vd-v1-` 64hex、tenant 必须等于 context tenant、source type/model/version/dimension/schema 匹配、operation=upsert、`ref.Validate()`、score finite [0,1]≥MinScore、duplicate document ID 保留最高分、MaxTotalCandidates 上限）→PostgreSQL hydration（batch/chunk 有界；missing/deleted/tombstoned/stale version/content-hash 漂移/projection scope 不匹配全部过滤；content freshness 用 server-owned `vector.ContentHash(content)` 重算证明）→确定性排序（score 降序、document ID 升序 tie-break）→TopK 截断。candidate expansion 有界：rounds ≤ MaxRounds、每轮 TopK×multiplier×round、总候选 ≤ MaxTotalCandidates；backend 返回不足即停止扩展；结果不足不伪装成功。cancellation/deadline 全程保留 context identity；unknown/unavailable 分类安全；不重试无限轮、不使用 fixed sleep。
- `postgres.go`：`PostgresHydrator` 读取权威 `memory` 表（tenant_id=$1 AND memory_id = ANY($2)，server-owned batch limit；只读 memory_id/scope/content/version/source_seq/deleted，不读 vector_ref/session 等无关列；PG 错误仅暴露 ErrUnavailable，无 raw SQL/DSN）。
- 映射说明：Milvus adapter（P1-06B，未修改）返回的 `SearchResult.Ref` 携带完整 server-owned `VectorDocumentRef`，且 adapter 已在映射时以 `serverDocumentID` 重算校验并拒绝跨 tenant hit；retrieval 直接以 `(tenant_id, memory_id=ref.SourceID)` 定位权威行，不使用 `memory.vector_ref`（保持 opaque 兼容语义）、不使用 content hash 冒充 identity、不新增 mapping 事实表、不修改 P0-09F。
