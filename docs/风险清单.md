## 1. 风险清单

| # | 风险 | 影响 | 缓解措施 | 状态 |
|---|---|---|---|---|
| **R1** | **Admin API 无认证** | 管理接口暴露导致租户数据泄露或误操作 | 当前依赖网络隔离（Docker 内网）；规划 Phase 2 实现 RBAC + SSO；生产环境禁止暴露公网 | 已知，规划中 |
| **R2** | **模型超时导致 Worker 阻塞** | 长尾请求（15% ~300s）占用 Worker 槽位，降低吞吐 | 300s 硬超时（`context.WithTimeout`）；`consumeWorkers` 信号量限制并发（默认 16）；超时后 context 取消，goroutine 正常退出 | 已实现 |
| **R3** | **IM 消息重复投递** | 同一消息被多次处理，导致重复回复 | 三层幂等：Redis SETNX（24h）+ Worker 检查 + MySQL UNIQUE 约束；DLQ 重放前 `ClearIdem` | 已实现 |
| **R4** | **Redis 单点故障** | 消息总线、锁、路由全部不可用 | 生产部署 Redis Sentinel 或 Cluster；Worker/Outbox/Gateway 在 Redis 不可用时降级（degraded 模式） | 部分实现（degraded 模式） |
| **R5** | **租户数据泄露** | SQL 查询缺少 `tenant_id` 过滤导致跨租户访问 | 所有 Store 层查询强制 `WHERE tenant_id = ?`；集成测试验证隔离（`TestMemoriesMySQLTenantIsolation`）；审计日志按租户分片 | 已实现 |
| **R6** | **密钥明文泄露** | IM token、模型 API key、数据库密码出现在日志或 trace 中 | 统一日志脱敏（正则匹配 password/secret/token/dsn/api_key → `***`）；审计错误类型为粗粒度分类（timeout/run_error）；Secret Manager 使用 AES-256-GCM 加密，master key 从环境变量读取不存储 | 已实现 |
| **R7** | **DLQ 消息积压** | 死信消息未被及时发现和处理 | `platform.dlq_total` OTel 指标告警；Admin API `GET /dlq` 支持按租户过滤；`POST /dlq/{id}/replay` 支持重放；`replayed_at` 防止重复重放 | 已实现 |
| **R8** | **后端迁移数据丢失** | 切换租户后端时旧数据未迁移 | `cmd/migrate` CLI 支持 Session/Memory 跨后端迁移（幂等：delete-then-create）；迁移前可快照配置（`tenant_config_versions`）；向量库可离线重建；对象存储可整体搬迁 | 已实现 |
| **R9** | **RBAC 表未接线** | `tenant_members`/`roles`/`role_permissions`/`member_roles` 表存在但无代码使用，可能误导后续开发者 | DDL 中保留，注释为「规划未接线」；当前权限模型 = 租户隔离 + Agent 工具白名单；Phase 2 实现完整 RBAC | 已标记 |
| **R10** | **IM 平台限制** | WeCom 2000 rune / Feishu 4000 rune 截断；流式消息/卡片未完全走通 | 出站文本自动截断（`truncateText` 按通道上限）；流式占位符已实现（WeCom 先发"正在处理…"再替换）；KindCard/KindStream 已定义待真实场景验证 | 部分实现 |

## 2. 缓解措施优先级

| 优先级 | 风险 | 行动 |
|---|---|---|
| **P0** | R1 Admin API 无认证 | 生产环境网络隔离 + Phase 2 RBAC |
| **P0** | R6 密钥明文泄露 | 已实现脱敏 + Secret Manager |
| **P1** | R2 模型超时 | 已实现 300s 超时 + 并发控制 |
| **P1** | R3 IM 重复投递 | 已实现三层幂等 |
| **P1** | R5 租户数据泄露 | 已实现隔离 + 集成测试 |
| **P2** | R4 Redis 单点 | 生产部署 Sentinel/Cluster |
| **P2** | R7 DLQ 积压 | 已实现指标 + Admin API |
| **P3** | R8 迁移丢失 | 已实现 migrate CLI |
| **P3** | R9 RBAC 未接线 | Phase 2 实现 |
| **P3** | R10 IM 限制 | 待真实场景验证 |
