# 企业微信与微信支持对照：按 PR 序号

本表按 PR 编号从小到大排列，仅包含渠道实现、功能边界和验证事实。证据链接直接指向对应冻结源码或项目接入说明。

- 核对日期：2026-09-15。
- 范围：批次 `2026-09-14-open-pr-astra-xhigh-v2` 保留的 19 个独立 PR；已关闭的重复 PR #5 不重复计入。
- 版本：逐一核对本地冻结 checkout 与该批次记录的 head SHA，19/19 一致，受跟踪源码无改动；结论不覆盖冻结后的提交。
- “已实现”表示查到实际协议收发代码及运行接线，不等于已在真实账号完整验收。“部分/预留/仅设计”不计为完整支持。“未见实现”限定于本次检查的冻结源码。
- 企业微信自建应用、智能机器人、微信客服、微信公众号、微信 iLink 分开统计；企业微信可用不能推导普通微信可用。iLink 指 PR 所实现的特定 ClawBot 接口，不泛化为任意个人微信账号自动化。
- WSS 指 WebSocket 加密长连接；Inbox 是持久入站记录，Outbox 是持久待发送记录；MCP 指以工具调用接口读取和发送消息。
- 验证情况引用本批次保存的测试执行与复核结论。本次进行源码/接线核查，没有重新运行 IM 测试、连接真实账号或发送消息。作者测试、作者现场记录和评审方独立验证分别表述；其他 IM/HTTP 的测试通过不转移为微信系通过。

## 支持概况

- 企业微信原生通道有实现：17 个；PR #21 为简化适配，PR #3 仅设计。
- 企业微信自建应用回调：9 个；智能机器人长连接：13 个；企业微信群消息 MCP：1 个。同一 PR 可以支持多种方式，数量不可直接相加。
- 微信客服有实际接收/拉取/发送实现：PR #18、#27。
- 微信 iLink/ClawBot 有收发及运行接线：PR #14。
- 微信公众号：未查到任何 PR 交付完整原生入站＋发送＋运行接线。PR #6 为类型枚举，PR #22 为 Provider/Sender 接口封装。
